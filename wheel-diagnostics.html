Wheel of Fortune — Diagnostics

Stage-by-stage check of the spin service. Read-only: no spin is performed, nothing is recorded, no prize is awarded.

#CheckResultDetail
Press “Run diagnostics” to start.

Runs entirely in your browser against the project configured in config.js. Stages 5–6 send crafted requests to the wheel-spin function and the public state RPC only — the spin-shaped request uses a non-existent campaign id, so the function stops at its identity guard and never reaches the prize roll.
